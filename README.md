# Chlorella

Windows 向けの表計算アプリです。

<img width="600" src="https://github.com/user-attachments/assets/4e7d057a-4a57-48f1-9f56-7061cea15013" />

.NET 8 SDK と Windows App SDK を使い、`dotnet build Chlorella.csproj -p:Platform=x64 -p:RuntimeIdentifier=win-x64` でビルドします。

起動するには PowerShell で `.\start.ps1` を実行します。
スクリプトはビルドに成功した後、アプリを起動します。

単独起動時は簡易エンジンを使用します。セルの入力・消去・コピー・切り取り・貼り付け、オートフィル、フォント・色・表示形式・配置、セルの結合、元に戻す／やり直す、シート操作、簡易 XLSX の保存と読み込み、CSV・HTML 出力に対応しています。Chlorella 間のコピーでは書式と結合を引き継ぎます。通常・値のみ・数式のみ・書式のみの貼り付けに対応しています。値のみは Ctrl+Shift+V でも実行でき、書式のみは Chlorella からコピーしたセルで利用できます。外部アプリからの貼り付けはテキストのみです。セル内編集では Alt+Enter で改行できます。全角数字だけの入力は半角に変換します。書式設定、セル結合、オートフィルは一度に 100,000 セルまでです。

数式は四則演算、べき乗、パーセント、同一シートのセル参照と範囲、`SUM`・`AVERAGE`・`MIN`・`MAX`・`COUNT` に対応しています。Excel と共通の構文を使いますが、他の関数、他シート参照、文字列や日付の計算など、Excel の数式全体には対応していません。循環参照は `#REF!` と表示します。関数の範囲は 100,000 セルまでです。

行・列の挿入と、行の高さ・列の幅の手動変更および自動調整に対応しています。行・列のサイズとシート見出しの色は保存されます。自動調整は文字数と書体サイズに基づく概算です。

シートの保護とパスワードによる解除に対応しています。パスワードは 15 文字以内で、Excel の従来方式のシート保護として保存します。これは誤操作を防ぐための機能であり、ファイルの暗号化ではありません。保護状態を切り替えると編集履歴は消去され、保護されたシートがある間は元に戻す／やり直す操作を利用できません。

数式を入力して確定すると、対応する閉じ括弧が不足している場合は末尾に補います。

図形の挿入・移動・サイズ変更・色・テキストの編集、画像の挿入・位置とサイズの変更、テーブルの挿入・範囲変更・解除、列の並べ替えと値によるフィルターに対応しています。フィルターで非表示の行を含む範囲の編集・コピー・切り取りは、誤操作を避けるため解除後に行います。図形・画像・テーブルは XLSX の標準形式でも保存します。テーブルの見出しに空欄・重複・数値・数式がある場合、セルの値を維持するため他の表計算アプリでは見出しなしとして表示し、フィルターを設定していた場合は非表示行を手動で再表示する必要があります。Chlorella では元の見出しとフィルター設定を保持します。PDF はセル、結合、図形、画像、行と列のサイズを反映します。文字幅と書体は画面と完全には一致しません。

外部の XLSX はセルの値・数式・結合、テーブル、値によるフィルター、基本図形、PNG・JPEG 画像を取り込めます。回転・反転された図形やトリミング画像、カスタムフィルターなど一部の要素とセルの書式は取り込まれません。共有数式・配列数式や保護されたシートは読み込めません。外部ブックや、他のアプリで変更された Chlorella ブックの読み込み元は上書きできず、保存には別のファイル名が必要です。

## インストール

GitHub Releases の Windows x64 用セットアップを実行します。既定のインストール先は `%LOCALAPPDATA%\Programs\Chlorella` です。Windows のアプリ一覧からアンインストールできます。

## コードのチェック

.NET SDK で書式と C# ソースの 140 文字以内の行を確認します。

```powershell
./scripts/lint.ps1
```

ビルド時には `.editorconfig` の型指定ルールも検査します。
